# Cuadro de mando Power BI

Coloca aquí el archivo `Dashboard Power BI Definitivo.pbix` (o el nombre que prefieras, p. ej. `WhiteHosting_Dashboard.pbix`).

El archivo pesa ~18 MB y no pudo descargarse automáticamente desde Google Drive en este proceso (supera el límite de 10 MB de la herramienta usada), por lo que debes añadirlo manualmente:

1. Descárgalo desde Google Drive a tu ordenador.
2. Cópialo dentro de esta carpeta `powerbi/`.
3. Inclúyelo en el commit antes de subir el repositorio (ver instrucciones en el README principal).
